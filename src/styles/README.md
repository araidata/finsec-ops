# Styles

Global Tailwind CSS and application design tokens are defined in
`src/app/globals.css`. Shared presentation primitives belong in
`src/components/ui`; module-specific layout belongs with the owning feature.

Preserve the established application shell, dense desktop financial workspaces,
Budget worksheet structure, and Maintenance Renewals register unless a task
explicitly authorizes redesign. New styling must retain keyboard focus,
readability, semantic structure, contrast, and responsive access to primary
workflows.

See [`docs/modules.md`](../../docs/modules.md) and
[`AGENTS.md`](../../AGENTS.md).
